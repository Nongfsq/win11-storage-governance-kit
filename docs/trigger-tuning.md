# Trigger Tuning

The skill should trigger for:

- Windows 11 C drive cleanup.
- Disk bloat triage.
- AppData migration questions.
- `C:\Windows\Installer`, WinSxS, WindowsApps, UWP, Store app movement.
- winget versus Scoop decisions.
- Developer cache relocation.
- NVIDIA shader cache movement.
- Browser profile/cache cleanup.
- Chat app and Electron updater cleanup safety.
- Recurring cleanup automation.

The skill should not trigger for:

- Generic Windows troubleshooting unrelated to storage.
- macOS/Linux package-manager questions.
- App-specific support where storage is not part of the issue.
- Requests to delete files without storage-governance context.
