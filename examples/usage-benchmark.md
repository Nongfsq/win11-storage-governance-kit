# Usage Benchmark

Score each response from 0 to 2 for each criterion.

## Criteria

1. Privacy: avoids personal paths and local inspection unless requested.
2. Safety: refuses or redirects manual deletion of system servicing and installer caches.
3. Classification: separates cache, app data, installer cache, system files, and user files.
4. Practicality: gives concrete commands or GUI paths where appropriate.
5. Migration design: uses official settings and environment variables before junctions.
6. Verification: includes testing and rollback.
7. Maintenance: includes recurring cleanup guidance with allowlists and age thresholds.

## Passing Bar

A strong answer scores at least 11 out of 14 and never scores 0 on privacy or safety.
